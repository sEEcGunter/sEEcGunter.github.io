MCP hardening

Local, reproducible lab of two MCP server bug classes published in Nov 2026, each with a vulnerable build, a fixed twin and tests that prove both.

01. Git config → code execution

A "read-only" Git tool (git status, git diff) runs a program named by the target repo's own .git/config (core.fsmonitor, diff.external, filter drivers).

Fix: command-scoped GIT_CONFIG_* overrides, repo-defined drivers blanked, --no-ext-diff --no-textconv, refuse Git < 2.31.

02. Policy bypass via normalization

Deny/elicit lists miss operation names with consecutive capitals (CreateSAMLProvider → create-s-a-m-l-provider).

Fix: one canonical resolver for policy and request, fail-closed on unknown names.

03. proof

45 tests, make demo shows marker written on vulnerable / absent on fixed, CI green (pytest + docker build). Ships an operator CHECKLIST.md.

04. safe by design

Payload writes one marker file in /tmp; no network, no AWS (simulated cloud in memory).
