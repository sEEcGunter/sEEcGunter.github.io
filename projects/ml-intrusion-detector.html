ml-intrusion-detector

An end-to-end network intrusion detection pipeline, the kind a SOC uses to flag suspicious traffic. It combines an unsupervised detector for unknown attacks with a supervised one for known patterns, and shows why default settings silently lie about performance.

  • Python
  • scikit-learn
  • XGBoost
  • Isolation Forest
  • SMOTE
  • NSL-KDD
  • UNSW-NB15

01. pipeline

raw flows ─► encode + scale ─┬─► Isolation Forest  (unsupervised · unknown attacks)
                             └─► XGBoost           (supervised · known patterns)
                                      │
                         PR-curve threshold tuning ─► stacking ─► multi-class triage
                                                                 (DoS · Probe · R2L · U2R)

02. the silent failure

A model with 0.97 ROC-AUC can still miss a third of attacks at the default 0.5 threshold. Flip the switch.
